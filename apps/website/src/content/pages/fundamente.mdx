## Ce intră în fundamente

Fundamentele sunt contracte comune, nu preferințe vizuale locale. Ele includ:

- principiile de proiectare a serviciilor;
- design tokens în format DTCG;
- rolurile cromatice și temele funcționale;
- tipografia, spațierea și grila responsive;
- focusul, motion, elevation și z-index;
- un set minim de iconițe decorative;
- regulile de accesibilitate și content design.

<Callout title="Regula principală" type="info">
  <p>
    Componentele consumă roluri semantice. Nu folosesc direct culori, dimensiuni sau valori de
    brand.
  </p>
</Callout>

## Cum sunt distribuite token-urile

Aceeași sursă DTCG generează CSS, TypeScript și JSON rezolvat. Artefactele nu sunt editate manual.

<CodeExample
  caption="Importul minim al fundației"
  language="css"
  code={`@import '@sistem-digital/tokens/css';
@import '@sistem-digital/tokens/themes.css';`}
/>

## Iconițe

`@sistem-digital/components` publică un set minim de iconițe decorative (`iconMarkup`, `iconNames`). Fiecare iconiță e `aria-hidden`, montată lângă text, niciodată în locul lui — nu înlocuiește un mesaj de status sau un label.

<CodeExample
  caption="Import și utilizare"
  language="ts"
  code={`import { iconMarkup } from '@sistem-digital/components';

iconMarkup('success'); // '<svg class="sd-icon" ...>...</svg>'`}
/>

<CodeExample
  caption="Importul CSS"
  language="css"
  code={`@import '@sistem-digital/components/icons.css';`}
/>

În M3, fiecare familie de fundamente va primi o pagină proprie, cu reguli, exemple, API și limite cunoscute. Până atunci, documentele normative din repository rămân sursa completă.
